# Historical Julia 1.10.12 pipeline records

These are byte-identical copies of the last Julia 1.10.12 pipeline records,
preserved before the approved Julia 1.12.5/upstream-lock environment migration.
They are historical evidence, not validation of the new environment.

The adjacent `docker-calibration-v1.*` and `final-validation-v1.*` reports
also belong to Julia 1.10.12 and remain unchanged. A complete old Task,
pipeline-state snapshot, original raw runs and protected old image tags are
retained outside the repository in the local work directory.

The CLI owns the current records in `comment/pipeline/`; new calibration
records there do not replace or reinterpret the historical files here.
